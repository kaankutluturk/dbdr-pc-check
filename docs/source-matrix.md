# Evidence source matrix

| Source | Purpose | Scope/minimization | Timestamp semantics | Failure meaning |
| --- | --- | --- | --- | --- |
| `Win32_Process` | Preserve live process identity and parentage | No command lines or owners | Process creation time from WMI | Snapshot unavailable/incomplete |
| `Process.Modules` | Record file-backed modules loaded by live DBD processes | DBD-named processes only; no addresses or memory | No source timestamp | Module-list coverage gap |
| File APIs / WinVerifyTrust | Hash and inspect referenced executables | Process/module and resolved persistence/task references only; no file copies; 2 GiB/file and 1,024 unique running-process path caps, prioritized toward DBD/user-writable locations | File times remain labeled fields | Per-file inspection or explicit cap gap |
| Bounded PE parser | Explain binary structure and loader-capable imports without extracting arbitrary strings | Max 96 sections, 4,096 named imports, 4 MiB entropy sample per section/32 MiB total; PDB basename only | COFF timestamp is labeled untrusted metadata | `not-pe`, malformed/capped or per-file inspection gap |
| Shannon entropy | Identify compressed/packed-like byte distributions for corroboration | Whole-file value during SHA-256 plus bounded PE-section samples; no extra path scope | No source timestamp | Per-file inspection gap |
| libyara 4.5.5 | Match embedded and optional custom rules against referenced files | Rule IDs/hashes only; killable same-EXE worker; 20-second/file timeout; 512 MiB file cap; 256 reported matches; custom rules 4 MiB and self-contained; no matched bytes, offsets or file copies | No source timestamp | Per-file YARA timeout/coverage gap or explicit size skip |
| BAM registry | Time-bounded execution observation | Explicit review window; SIDs excluded | BAM FILETIME | Layout/key access gap |
| Prefetch directory | Corroborating parsed execution history | Executable name, format version, run count and last-run FILETIMEs in explicit review window; 4,096-file, 16 MiB compressed-input and 64 MiB declared-output caps | Parsed last-run FILETIME | Directory/access/parser/cap gap |
| System event 7045 | Service-install observation | Selected event ID only; account field/message excluded | Event creation time | Channel/query gap |
| Code Integrity operational log | Unsigned-driver, signing failure, audit, block and correlated signature observations | Selected event IDs and whitelisted signing/path fields only; message and other payload excluded | Event creation time | Channel/query/retention gap |
| Live Amcache registry | Corroborating executable application inventory | Opt-in; executable file types only; redacted paths; 5,000-record cap; no key hashes or user identities | No source timestamp; link date remains labeled file metadata | Hive/layout/access/cap coverage |
| Application Error event 1000 | Crash and fault-module observation | Opt-in; selected fields only; message, report ID and dumps excluded | Event creation time | Channel/query/layout gap |
| Windows PowerShell events 400/403/600 | Engine and provider lifecycle observation | Opt-in; system metadata only; event payload, command/script content, host arguments and users excluded | Event creation time | Channel/query/retention gap |
| NTFS USN change journal | Recent executable/script file changes and create/delete sequences | Opt-in; fixed NTFS volumes; 64 MiB and 250,000 parsed records per volume; 5,000 emitted execution-capable leaf filenames; no parent paths, file references or content | USN record timestamp | Access/journal-retention/tail-cap gap |
| Microsoft `powercfg /srumutil` | Corroborating executable application-usage buckets | Opt-in; 64 MiB temporary XML/60 s/5,000 record caps; executable name and redacted path only; user, network, interface, destination, amount and opaque-ID fields discarded | SRUM bucket timestamp inside the case window | Command/export/schema/identity-resolution/cap coverage |
| Autorun registry locations | Run keys, Explorer policy Run, Winlogon, AppInit, boot-execute, LSA packages and IFEO debugger persistence | Selected executable references/package values only; arguments excluded; paths redacted; no referenced content opened outside executable scope | No source timestamp | Registry view/key access gap |
| Startup folders | Targeted startup persistence metadata | Top-level filename, extension, redacted path and last-write time; no file or shortcut content; 512-file cap per folder | File last-write time | Folder/access/cap gap |
| WMI `root\subscription` | Permanent event-consumer identity | Consumer name/class only; commands, scripts, filters, queries and payload excluded; 512-record cap | No source timestamp | WMI access/version/cap gap |
| Persistence executable references | Current persistence configuration plus binary identity/triage | Resolved driver, auto-start service, Run/Winlogon/AppInit/IFEO and direct Startup executable references; max 512 unique paths | No source timestamp | Source-specific, resolution-cap or per-file gap/warning |
| PSAPI loaded drivers | Current loaded kernel image paths as a dump-free kernel signal | File name and redacted image path only; kernel base addresses excluded; resolved files enter bounded enrichment | No source timestamp | API/path-resolution/SeDebugPrivilege gap; Windows 11 24H2 can return all-null values |
| Registry + `Win32_DeviceGuard` | Windows code-integrity and kernel-hardening posture | No device instance identifier or user identity | No source timestamp | Registry/WMI access or version gap |
| Scheduled task definitions | Current task persistence configuration and executable enrichment | Command only; arguments/principals excluded; 5,000 definitions, 4 MiB/definition and 256 unique resolved binaries | Registration date where parseable | Per-task, directory, parser or enrichment-cap gap |
| `Win32_PnPEntity` | Privacy-minimized device context | Unique IDs and serial suffixes excluded | No source timestamp | Device-inventory gap |

MFT remains disabled pending its separate raw-volume parsing and timestamp review. The bounded USN and minimized SRUM sources are opt-in; exact redacted-path correlation uses only already approved normalized records and requires an independent binary review signal. Browser data, PowerShell command/script content and memory-dump collection remain privacy-gated exclusions.
